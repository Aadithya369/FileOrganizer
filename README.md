#About
is a command line utility tool that organizes your messy folders by creating sub directories based on your file extensions and puts your files into their respective directories.

##Requirements
```
- GCC compiler
  or
- any compiler with *POSIX* compatibility 
```

#How to run :
<pre> 
  ```
  `clone` the repository using 
  git clone git@github.com:Aadithya369/FileOrganizer.git

  gcc program_name && ./a.out

  Enter the `PATH` of the folder you want to organize.
  
  ```
