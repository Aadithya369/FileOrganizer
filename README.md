# About
A command line utility tool that organizes your messy folders by creating subdirectories based on your file extensions and puts your files into their respective directories.

## Requirements
- GCC compiler  
  or  
- any compiler with _POSIX_ compatibility

## How to run

```sh
# Clone the repository 
git clone git@github.com:Aadithya369/FileOrganizer.git

# Compile the program 
gcc program_name && ./a.out

# Enter the PATH of the folder you want to organize.
```

## Libraries used

### Windows & Linux
- `<stdio.h>`
- `<stdlib.h>`
- `<string.h>`
- `<stdbool.h>`
- `<errno.h>`

### Windows only
- `<direct.h>`

### Linux only
- `<unistd.h>`
- `<sys/stat.h>`
- `<sys/types.h>`
